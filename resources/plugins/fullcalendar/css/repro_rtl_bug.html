Chrome RTL Scroll Bug Repro

This demonstrates the issue where Chrome may miscalculate the scroller's position in RTL mode when `overflow: hidden` is on the parent. The hack forces `direction: ltr` on the harness and reverts to `rtl` on the scroller.
